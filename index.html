Configuración de Cloudflare Pages

Has desplegado la rama de código fuente (main). Para ver la aplicación móvil funcionando directamente en Cloudflare Pages, ajusta la rama de producción:

  1. En tu panel de Cloudflare Dashboard, entra a tu proyecto de Pages.
  2. Ve a Settings > Builds & deployments.
  3. Cambia Production branch a: gh-pages
  4. Asegúrate de que Build command esté vacío y Output directory sea /.
  5. Haz clic en Save y re-despliega.
